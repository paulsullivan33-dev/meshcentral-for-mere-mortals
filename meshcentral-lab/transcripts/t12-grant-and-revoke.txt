Granting and revoking rights on a group (transcript t12)
=============================================================
Continues t11: labtech could see no devices. The admin grants
labtech one right - remote control only - on the Lab Machines
group. MeshCentral rights are a bitmask; the bits used by the
official MeshCtrl tool include:

  1 edit group      2 manage users     4 manage devices
  8 remote control  16 agent console   32 server files
  64 wake devices   128 notes          256 desktop view only
  512 no terminal   1024 no files      32768 uninstall
  4294967295 (0xFFFFFFFF) = every right there is

   "userids":["user//labtech"], "meshadmin":8}

  -> {"action":"addmeshuser","responseid":"lab1",
      "result":"Added user labtech","success":1,"failed":0}
